Stocket — Design Handoff Brief

Referensi teknis untuk mendesain ulang Stocket secara mandiri. Berisi inventaris 3 halaman yang ada sekarang (apa isinya, bukan tampilannya), style guide yang sedang dipakai kode, dan batasan teknis (stack, library chart, breakpoint) yang perlu dipertimbangkan saat desain — supaya begitu desainmu siap, aku bisa implementasikan persis tanpa harus menebak ulang struktur datanya.

Style guide

Warna

Token warna asli didefinisikan di index.css lewat Tailwind v4 @theme — jadi otomatis jadi CSS variable sungguhan. Tema gelap adalah default (bukan opsional); Stocket belum punya mode terang.

Halaman 3 / 3

Detail Emiten

Satu-satunya halaman yang fullscreen — tidak memakai nav/footer situs biasa, dibuka saat klik sebuah saham dari manapun. Berisi grafik candlestick + semua hasil analisis.

Halaman ini pakai library chart lightweight-charts (punya TradingView sendiri, open-source). Kalau desainmu mengubah tata letak chart, ingat: candlestick + volume ada di panel harga utama, RSI di panel terpisah di bawahnya (hanya muncul saat diaktifkan), MA jadi garis di panel harga yang sama.
Detail Emiten (fullscreen)/emiten/:symbol
  1. Header sendiriLogo (kembali ke dashboard) + search simbol — bukan header situs biasa
  2. Toolbar gambar (kiri)Strip ikon vertikal: kursor, garis horizontal, garis tren (klik 2 titik), hapus semua — fungsional nyata, bukan dekorasi
  3. Ticker headerSimbol · Nama · 1D · IDX, lalu O/H/L/C, perubahan (±nilai, ±%), tanggal — mono, sejajar seperti quote bar
  4. Toolbar chartToggle rentang waktu 1Bln/3Bln, toggle indikator MA/RSI (default OFF), tombol layar penuh
  5. Grafik hargaCandlestick + volume histogram + penanda pola candlestick + (opsional) MA overlay + (opsional) panel RSI
  6. Panel kanan (collapsible)Tab kecil untuk buka/tutup. Isi berurutan: nama+skor komposit besar, penjelasan indikator (jika aktif), daftar pola candlestick, 5 komponen skor (score bar), framework Piotroski (kriteria ✓/✗), deteksi anomali + berita terkait, perbandingan peer (list scrollable), kemiripan pola (lazy-load)
  7. AI mengambangIkon bulat kanan-atas, fixed (ikut scroll) → klik buka popup chat kecil, menimpa konten di bawahnya
  8. Strip disclaimerSatu baris tipis di paling bawah — tetap wajib ada meski halaman fullscreen

Referensi teknis

Batasan yang perlu dipertimbangkan
AreaBatasan
StackReact + Vite + TypeScript, styling via Tailwind CSS v4
Chartlightweight-charts — mendukung candlestick, line, histogram, multi-pane, price line. Tidak ada mesin gambar bebas (baru 2 tool: garis horizontal & tren)
Rentang data hargaMaksimal 90 hari per panggilan API (batas dari Sectors) — jangan desain fitur yang butuh data >90 hari tanpa diskusi dulu
IkonBelum ada set ikon custom — dipakai karakter unicode/emoji sebagai placeholder. Kalau desainmu butuh ikon asli, sertakan sebagai SVG
TemaGelap saja, permanen. Belum ada mode terang
